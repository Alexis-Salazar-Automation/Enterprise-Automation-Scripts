# Enterprise Automation Scripts Collection 🚀

Este repositorio es un ecosistema de herramientas de automatización diseñadas para optimizar procesos de negocio, auditoría de datos y flujos de trabajo de alto volumen. Cada solución está enfocada en generar un **ROI medible** mediante la reducción de tiempos operativos y la eliminación del error humano.

---

## 📂 Inventario de Soluciones

### 🏛️ Infraestructura de Datos (Python)

#### 1. [Portfolio Sync Engine (Python & GitHub Actions)](./Python/Portfolio-Sync-Engine/)
**Impacto:** Corazón de datos del área. Eliminación del 100% de errores por omisión manual.
- Orquestación automática de cartera mediante GitHub Actions.
- Sincronización dinámica entre APIs privadas y Google Sheets.
- Generación de reportes de variaciones diarios y respaldos en Drive.

---

### ⚙️ Automatización de Procesos Core (Google Apps Script)

#### 2. [Agreement Management Suite](./Google-Apps-Script/Agreement-Management-Suite/)
**Impacto:** Reducción del 95% en tiempos de respuesta (de 3 min a 5 seg).
- Gestión integral de convenios y negociaciones para carteras de +60k registros.
- Lógica de filtrado en cascada y generación automatizada de acuses en PDF.

#### 3. [Direct Debit Control Suite](./Google-Apps-Script/Direct-Debit-Control-Suite/)
**Impacto:** Garantía de integridad de datos y salud de cartera.
- Auditoría automática de estatus de domiciliación vs. cartera maestra.
- Dashboard de KPIs diarios enviado por correo con alertas de morosidad.

#### 4. [Post-Sales Bulk Data Synchronizer](./Google-Apps-Script/Post-Sales-Bulk-Sync/)
**Impacto:** **Ahorro de 5 horas diarias** de trabajo manual de descarga.
- Consolidación masiva de +200 condominios en una sola base operativa.
- Implementación de auto-reinicio para bypass de límites de ejecución de Google.

### 📊 Inteligencia de Negocio y Auditoría

#### 5. [Govt Tax Scraping Suite](./Google-Apps-Script/Govt-Tax-Scraping-Suite/)
**Impacto:** Consulta masiva de +25,000 registros mensuales.
- Web scrapers con gestión avanzada de Tokens dinámicos y Cookies de sesión.
- Bypass de sistemas legacy para auditoría fiscal automatizada.

#### 6. [Bulk Status & Assignment Manager](./Google-Apps-Script/Bulk-Status-Assignment-Manager/)
**Impacto:** Actualizaciones masivas sin saturación de servidores.
- Estrategia de **Chunking** para procesamiento de lotes de alto volumen.
- Interfaz de monitoreo en tiempo real con sistema de *cooldown* automático.

#### 7. [Telephony Analytics & Auditor](./Google-Apps-Script/Telephony-Analytics-Auditor/)
**Impacto:** Visibilidad total del desempeño del equipo.
- Análisis de efectividad de llamadas mediante **RegEx** y lógica de duración.
- Generación de reportes ejecutivos automatizados en HTML/CSS.

#### 8. [Mass Notification Engine](./Google-Apps-Script/Mass-Notification-Engine/)
**Impacto:** Comunicación masiva omnicanal (Email/WhatsApp).
- Algoritmo de **Auto-Sanación** de payloads para garantizar la entrega.
- Modos de envío dual (Seguro vs. Urgente) según volumen de datos.
